# 编译与运行

> 审阅状态：本页仅整理旧式 `makefile` 的可见依赖和运行入口，**不是已在本环境完成的可复现构建记录**。PETSc/HYPRE/MPI/编译器 ABI、`control.dat` 和网格/IBM 输入均需要在目标系统实际核验。

## makefile 分析

当前 `makefile` 使用：

```make
CC  = mpicxx
CXX = mpicxx
```

目标 `all` 编译所有对象后链接为可执行文件 `test_`。源文件清单包括工具函数、网格、数据、LES、壁面模型、边界条件、Poisson、RHS、积分器、IBM、FSI、探针、平面抽取、流场求解器、结构求解器和 `main.o`。

编译参数：

```make
CPPFLAGS = -I$(PETSC)/include -I$(HDF5)/include -g -Wno-unused-result -O3
```

链接目录和库：

```make
LIBDIR = -L$(PETSC)/lib -L$(HDF5)/lib
LIBFLAG = -lpthread -lrt -ldl -lstdc++ -lpetsc -lHYPRE -lgfortran \
          -lblas -llapack -lX11 $(HDF5)/lib/libhdf5.a \
          $(HDF5)/lib/libhdf5_hl.a -lz
```

需要注意，`PETSC` 和 `HDF5` 路径硬编码为作者本地目录：

```make
PETSC = /home/danny/software/petsc/petsc-3.4
HDF5  = /home/danny/software/hdf5/hdf5
```

在新环境运行前必须修改为实际安装路径，且 PETSc 版本较老，API 使用也偏 PETSc 3.4 风格。

## 依赖库

必须依赖：

- MPI C++ 编译器 `mpicxx`
- PETSc，包含 Vec、DMDA、SNES、KSP、Viewer、HDF5 Viewer
- HYPRE，包含 IJ/ParCSR、BoomerAMG、GMRES/PCG
- HDF5 和 HDF5 high-level 库
- BLAS/LAPACK
- gfortran runtime
- zlib、pthread、rt、dl、X11

后处理脚本依赖：

- Python 2 语法环境
- numpy
- h5py

`data.py` 使用 `print` 语句和 `xrange`，不能直接在 Python 3 下运行，除非先做兼容性修改。

## 输入文件

运行时主程序固定读取当前目录下 `control.dat`：

```cpp
PetscOptionsInsertFile(PETSC_COMM_WORLD, "control.dat", PETSC_TRUE);
```

因此通常需要在运行目录放置：

- `control.dat`：PETSc option 格式控制文件。
- `bcs.dat`：一行 6 个整数，分别表示 i-、i+、j-、j+、k-、k+ 边界类型。
- `grid.dat` 或 `xyz.dat`：网格文件，除非使用 `-uniform`。
- IBM 算例需要对应的 IBM 几何文件，文件名由 `ReadUCD` 内部按 body 编号和路径规则读取。
- `savepoints`：可选点探针坐标文件。
- `savekplanes`：可选平面抽取 k 索引文件。

常用控制选项包括：

- 时间：`-dt`、`-totalsteps`、`-rstart`、`-St`
- 物性：`-ren`
- 输出：`-tio`、`-tiou`、`-tieu`、`-hdf5`、`-write_hdf5`、`-read_hdf5`
- 路径：`-path`、`-field_path`、`-average_path`、`-phase_path`、`-flow_path`、`-inflow_path`
- 网格：`-grid`、`-xyz`、`-binary`、`-uniform`、`-IM/JM/KM`、`-Lx/Ly/Lz`
- 周期：`-i_periodic`、`-j_periodic`、`-k_periodic`、`-ii_periodic`、`-jj_periodic`、`-kk_periodic`
- LES：`-use_les`、`-les`、`-max_cs`、`-les_eps`
- Poisson：`-poisson_it`、`-poisson_tol`、`-amg_thresh`、`-amg_coarsentype`、`-amg_agg`
- IBM/FSI：`-imm`、`-body`、`-fsi`、`-rfsi`、`-rbody`、`-str`、`-str_tol`

## 输出文件

主要流场输出由 `UData::WriteData` 控制：

- `vfield%06d_0.dat/h5`：逆变速度 `ucont`
- `ufield%06d_0.dat/h5`：笛卡尔速度 `ucat`
- `pfield%06d_0.dat/h5`：压力 `pressure`
- `nvfield%06d_0.dat/h5`：IBM 标记 `nvert`
- `cs%06d_0.dat/h5`：LES 动态系数
- `Kinetic_Energy.dat`：总动能诊断

统计输出在 `average_path`：

- `su0/su1/su2`：速度一阶、交叉、平方和
- `sp/sp2`：压力和与压力平方
- `su3/su4/su5/svo/svo2`：更高阶统计、涡量相关量

FSI 输出在 `fsi_path`：

- `FSI_positionXX.dat`
- `FSI_AngleXX.dat`
- `DATA_FSIxxxxx_XX.dat`
- `Force_Coeff_SIXX_0.dat`
- `Momt_Coeff_SIXX_0.dat`
- `Power_SIXX_0.dat`

探针输出为 `Flow0_...dat` 和 `Flow1_...dat`。平面抽取输出为二进制 `inflow_%06d_dt=...dat`。

## 运行方式

典型流程：

1. 修改 `makefile` 中 `PETSC` 和 `HDF5` 路径。
2. 在 `vwis2.0/` 源码目录编译：

```bash
make
```

3. 在运行目录准备 `control.dat`、`bcs.dat`、网格和可选 IBM/探针文件。
4. 运行：

```bash
mpirun -np 8 ./test_
```

若在源码目录外运行，需要确保可执行文件、`control.dat` 和相对路径设置一致。代码大量使用 `-path` 和其他路径选项拼接文件名，建议在 `control.dat` 中显式设置所有路径。

## 后处理

若使用 HDF5 输出，可用：

```bash
python data.py --create_grid
python data.py --iterations 0 1000 100 --directory ./fields
python data.py --iterations 0 1000 100 --directory ./fields --time
```

平均量：

```bash
python data.py --iterations 1000 2000 100 --average 3 --average_directory ./average
```

脚本会生成 `grid.h5`、`xfield*.xdmf`、`xtime*.xdmf`、`a*_field*.h5` 和 `xavefield*.xdmf`，供 ParaView/VisIt 读取。

## 编译和维护建议

当前构建系统较老，建议后续改进：

- 用环境变量或 PETSc 自带 `petscvariables` 替代硬编码路径。
- 明确 HYPRE 和 PETSc/HDF5 ABI 兼容版本。
- 加入 `-Wall -Wextra` 后修复无返回值、重复声明、疑似错误赋值。
- 将 `control.dat` 示例和每个边界类型的说明纳入版本库。
- 将 Python 2 后处理脚本迁移到 Python 3。

## 运行前数值检查

编译成功不等于数值正确。每个新平台至少记录：输入 `dt` 与 `CalculateMinimumDt` 尺度、SNES 残差/迭代数、HYPRE 残差/迭代数、`CalculateDivergence`、入口/出口/IBM 通量和重启差异。比较不同 MPI 分块的这些量与积分力，才可验证 ghost、边界和归约路径。

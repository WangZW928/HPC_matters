## 设计取舍与下一步

用独立 face `MultiFab` 表达 `Ucont`，而不是复用旧三分量 DMDA 视图；将
`Nvert` 保持为 legacy 分类而不假定 EB 体积分数；物理 ghost 明确留给 BC
functor，不能由 `FillBoundary` 冒充。schema metadata 不伪装成 restart 文件。

下一步应提供受版本控制的旧 solver case/网格/输出，安装并记录锁定 AMReX，
执行 CMake、ctest 及 1/多 rank halo 比较；随后逐面冻结 BC 和 pressure datum，
再进入 P2 cell/face 映射与 P3 physical BC。不得在这些门槛前实现或宣称 RHS、
投影、LES、IBM、FSI 或 AMR 物理算法。

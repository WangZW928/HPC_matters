# AMReX P8-003 uniform sampling and statistics

_VWiS to AMReX incremental implementation report — 2026-08-29_

## Scope and conclusion

This increment completes the declared P8-003 subset for a single-level,
uniform Cartesian, single-process CPU run. It adds reusable point, plane, and
instantaneous flow diagnostics, deterministic CSV/JSON output, and practical
time averages in the existing physical-channel benchmark.

This is an engineering/manufactured contract result, not evidence of full CFD
correctness. No AMReX plotfile writer was added, and the JSON/CSV formats are
explicitly marked as not plotfile-compatible.

## Implemented contract

- A physical-coordinate point probe selects the containing cell in a half-open
  domain and reports cell index/centre, velocity, pressure, and divergence.
- Plane statistics report cell count, coordinate, mean velocity, mean pressure,
  and integrated normal `Ucont` flow on the section's low face.
- Plane extraction writes deterministic, index-sorted CSV rows containing
  `i,j,k,x,y,z,u,v,w,pressure,divergence`.
- Instantaneous flow diagnostics report integrated/max-absolute divergence,
  net physical-boundary mass flux, outlet flow, momentum, kinetic energy, and
  pressure mean/minimum/maximum.
- The physical Cartesian channel uses these APIs at every post-step sample and
  emits arithmetic averages over its 40 equally spaced samples.

The checkpoint Header/payload and restart code were not changed. The existing
P8-001/P8-002 focused tests remain part of the P8-003 focused run.

## Deterministic regression

`p8_sampling_statistics.in` uses a periodic `4x3x2` domain split into multiple
Boxes, constant `U=(1,2,3)`, and `P=100*i+10*j+k`. The executable checks values
internally with a roundoff-scaled tolerance. PASS requires:

- probe cell `(2,1,1)`, pressure `211`, and zero divergence;
- x-plane index 1 with six rows, mean pressure `110.5`, and normal flow `1`;
- zero integrated and maximum divergence;
- momentum `(1,2,3)`, kinetic energy `7`;
- pressure mean/minimum/maximum `160.5/0/321`;
- JSON schema/status markers and an exact CSV header plus six data rows.

The physical-channel CTest checks that the reusable diagnostics and 40-sample
time-average fields are present. It remains labelled `physical run / not yet
validated` because there is no legacy or literature reference baseline.

## Explicit limitations

- Sampling is cell-containing/cell-centred; interpolation is not implemented.
- Diagnostics and section output deliberately reject MPI rank counts other
  than one and GPU builds. No cross-rank probe ownership/gather is claimed.
- There is one uniform level only; AMR finest-level coverage and coarse/fine
  duplicate suppression do not exist.
- IBM/EB is not implemented, so body force/moment and IBM-neighbour statistics
  are deferred to P6-005 rather than synthesized from unrelated boundaries.
- Pressure retains the existing nondimensional/datum contract; diagnostics do
  not establish a physical SI conversion.
- CSV and JSON are purpose-specific diagnostic formats, not AMReX plotfiles,
  HDF5, or legacy PETSc-compatible output.

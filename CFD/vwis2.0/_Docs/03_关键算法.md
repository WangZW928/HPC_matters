# 关键算法

## 空间离散

代码采用结构化曲线网格上的有限体积/有限差分混合表达。守恒量以面通量形式存储，散度由相邻面通量差计算，因此连续性方程是典型有限体积形式。速度梯度、压力梯度和 LES 应变率则通过曲线坐标差分和度量变换得到。

曲线坐标度量由 `CurvGrid::FormMetrics` 从节点坐标计算：

- 面面积向量通过两条局部边向量叉乘得到。
- 中心度量由相邻面度量平均。
- Jacobian 用坐标变换行列式求倒数。

对流项默认使用面通量乘速度插值。内部有四阶中心型插值：

`(-u_{L} + 9 u_C + 9 u_R - u_{RR}) / 16`

靠近边界、IBM 标记或设置 `-second_order` 时退化为二阶/局部格式。粘性项使用速度梯度和曲线坐标 metric tensor 形成面粘性通量，再求通量散度。

## 压力 Poisson 方程

压力修正满足离散形式：

`div(grad(Phi)) = - coeff * div(U*) / dt`

其中 `coeff` 来自时间积分系数和 `St`。矩阵模板最多 19 点，对角、6 个面邻居和曲线网格交叉项都被考虑。IBM 固体单元不进入压力未知量；`Setup` 将流体压力点压缩为 `Phi2`，减少 HYPRE 方程规模。

线性求解：

- 数据结构：HYPRE IJMatrix/IJVector，底层 ParCSR。
- 默认：GMRES + BoomerAMG。
- 可选：定义 `PCG_POISSON` 后使用 PCG + BoomerAMG。
- AMG 参数：插值类型 13，默认 PMIS coarsening 8，强连接阈值默认 0.3，最大外迭代默认 11，容差默认 `5e-9`。

封闭或全 Neumann 压力系统通过 `RemoveNullspace` 把 RHS 均值移除，避免常数零空间导致迭代漂移。

## 时间推进

动量方程使用 PETSc SNES 非线性隐式求解。`Integrator` 将动量残差注册给 SNES，默认使用 Newton trust-region 方法和矩阵自由 Jacobian。当前代码中 RHS 在残差回调里用试探速度重新计算，因此对流项和部分粘性项是非线性隐式处理。

历史向量包括：

- `Ucont_o`：上一真实时间步。
- `Ucont_rm1`：再上一时间步。
- `Rhs_o`：旧步 RHS。

这表明代码意图使用二阶多步或半隐式时间离散。压力投影中 `timeCoeff` 进入 RHS 和速度修正，实际系数由 `UData` 管理。

## IBM 边界算法

IBM 算法分几何搜索和速度插值两部分。

几何搜索：

1. 对每个浸入体求扩展包围盒。
2. 将三角面分配到固定 40x40x40 空间桶。
3. 对候选网格单元中心发射随机/准随机射线，统计与三角面的相交判定内外。
4. 对薄体可用 `PointCellThin` 检测单元边与三角面穿越。
5. 生成 `Nvert` 固体掩码，并标出流固界面附近单元。

插值边界：

1. 对近界面流体点找最近三角元和表面截距。
2. 在流体侧寻找 image/interception point。
3. 存储三角形重心系数和流体插值点权重。
4. 用体表速度 `Ua`、流体插值速度 `Uc` 和距离 `sb/sc` 构造边界点速度。
5. 可选择 no-slip、free-slip 或壁函数模型。

这类方法对界面清晰、适合复杂运动几何，但搜索和插值逻辑较复杂，对 `Nvert` 状态一致性敏感。

## LES 亚格子模型

常数模型：

`Cs = 0.01`

动态模型：

1. 从 `Ucat` 计算速度梯度和应变率张量。
2. 用 3x3x3 Simpson 型测试滤波得到滤波速度、速度乘积和应变率组合。
3. 形成 Germano 关系中的 `Lij`、`Mij`，累积 `LM` 和 `MM`。
4. 可选在一个均匀方向上做 MPI 全局平均。
5. `Cs = 0.5 LM/(MM + les_eps)`。
6. 将 `Cs` 裁剪到 `[0, max_cs]`，近壁/IBM 区域使用下限或置零。
7. `nu_t = Cs Delta^2 |S|`。

代码中 `Cs` 变量实际更像 Smagorinsky 系数平方后的组合系数，因为涡粘公式直接用 `Cs*Delta^2*|S|`，不是 `(Cs*Delta)^2*|S|` 的常见写法。使用时应按代码定义解释输出。

## 壁面模型

壁函数包含两类：

- 简化幂律/对数律：基于 `A=8.3`、`B=1/7`、`kappa≈0.4`，粗糙壁用 `ks*0.033` 修正。
- Cabot 型积分：对 `1/(1+nu_t/nu)` 沿壁法向积分，通过 Newton 法匹配切向速度求 `u_tau`。

`WallModel` 将壁面模型结果转为粘性通量修正。对于 LES 壁模，这比简单设置边界速度更进一步，因为它把近壁剪切应力直接反馈到动量 RHS。

## FSI 耦合算法

平移 FSI 使用简化单自由度/多方向弹簧-阻尼模型：

`x'' + 2 damping * red_vel * x' + red_vel^2 * x = mu_s * F`

代码以固定迭代次数更新位置和速度，方向由 `-dgf_x/-dgf_y/-dgf_z` 控制。移动后 IBM 顶点坐标为初始坐标加结构位移，顶点速度为结构速度。

旋转 FSI 使用角位移和角速度状态，支持规定角速度、流体力矩驱动和绕指定轴旋转。`CalculateForces1` 通过压力和粘性应力在固体界面附近积分力、力矩、功率和阻力/推力相关量。

耦合策略是分区迭代：流体力更新结构，结构移动 IBM，流体在新几何上重算。强耦合能力取决于 `-str` 和结构收敛判断。

## 代码层面注意点

关键算法实现中存在一些应纳入验证的细节：

- 部分模块有明显复制粘贴痕迹和重复声明，易造成隐藏错误。
- `PoissonRHS2_hypre` 中 `JAj` 读取为 `getlKAj()` 的重复语句疑似错误。
- `WallFunctions::utau_wf` 光滑壁分支没有返回值。
- `ImmersedBoundary` 构造函数的 `if (d_immersed)` 缺少花括号。
- `StructSolver::CheckConvergence` 的返回逻辑与变量名可能相反。

这些不改变本文对算法意图的判断，但会影响特定算例的鲁棒性。

## 实施内容

- `VwisAmrExSolver.H/.cpp`：字段注册扩展为 `P/Phi/Nvert` cell 标量、`Ucat`/`Ucat_old` cell 三分量，以及 x/y/z 三个独立的单分量 face `Ucont` 时间层 `n/n-1/n-2`；每项记录 location、components、nGrow、units、time layer、component names 和 ownership。
- 断言 cell 字段为 cell-centered，`Ucont[d]` 为 d-normal node-centered face，并要求其 BoxArray 等于对应 `convert(m_ba, dimension_vector(d))`；`Nvert` 明确不是 EB volume fraction。
- 记录 Cartesian `dx` 与 cell volume；contract 用常量 `Ucat=(1,2,3)` 和 `Ucont=(1,2,3)` 检验三分量 cell 语义与三方向 face 语义不混淆，并继续检验多 Box/MPI periodic halo。

- 新增 `inputs/p2_contract.in`，CTest runtime contract 改用该 P2 输入；保留 P1 输入和历史报告。
- 任务清单更新：P2-001/P2-002 标为“已完成”，P2-003/004/005 保持“未开始”。

## 算法审查订正（最终有效，2026-08-21）

### 问题与修正

- **高**：第二增量把 `Ucont` 当 face-normal velocity，cell→face 未乘面积、
  face→cell 未除面积，derived divergence 又按速度差除 `dx`。legacy
  `FormMetrics` 的叉积、`Contra2Cart` 和 `Aj × 面通量差` 共同证明
  `Ucont=Ucat·面积余因子`。已改为 Cartesian $U_d=u_dA_d$，散度 stencil 改为
  净面通量/单元体积。
- **中**：原测试没有验收任务表声称的唯一 face sum，也没有独立验证 face
  grow cells；共享 face 的一致值不能证明不会双计数。已加入
  `OwnerMask/sum_unique` 的唯一面数/通量和，以及周期、inter-Box/MPI、非周期
  外部 face ghost 的定向检查。
- **中**：`run_contract_checks` 原来隐式调用 P2 transform，使
  `p1_contract.in` 的证据边界混入 P2。两个开关现已独立，`p2_contract.in`
  显式启用两组检查；基础检查只验 cell layout/初始化/halo/物理边界未填充，
  体积通量、metric、face ownership 和 derived divergence 均只在显式 P2 路径验收。
- **中（文档）**：删除 `jacobian=1` 的含糊声明，改记未分配的
  `legacy_Aj_equivalent=1/cell_volume`；明确非周期 domain face 的邻接单元复制
  是 P2 零阶外推，不是物理 BC。

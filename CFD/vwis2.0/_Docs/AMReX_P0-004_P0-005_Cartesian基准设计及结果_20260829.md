# AMReX P0-004/P0-005 Cartesian 基准设计及结果

_2026-08-29；`amrex_port` 的可重复 CPU benchmark 基础设施记录_

---

## 📋 结论与边界

`p0_cartesian_benchmark.in` 选择当前可真实运行的最小路径：全周期、单层均匀
Cartesian 网格上的 divergence-free shear，调用已有显式 Euler 动量预测和
Cartesian pressure projection。该算例是 **manufactured/contract baseline**，不是
legacy vwis 算例、不是 legacy SNES 对照，也没有 CFD 物理正确性或 legacy 数值等价
声明。仓库当前没有冻结的 legacy control/BC/reference-output case，因此 P0-004 和
P0-005 保持“进行中”。

## ⚙️ 输入与输出契约

| 项目 | 基线值 |
| --- | --- |
| 输入 | `amrex_port/inputs/p0_cartesian_benchmark.in` |
| 网格 | `16 × 8 × 8`，`max_grid_size=4`，`nghost=2`，物理域 `[0,1]^3` |
| `dt` / `nu` | `0.001` / `0.1` |
| 步数 / 终止时间 | `8` / `0.008` |
| BC | x/y/z 全周期 |
| pressure datum | 周期投影 correction zero mean |
| 制造初场 | `U=(0,sin(2πx),0)`，无净通量、离散散度为零 |
| 输出 | CTest 工作目录下 `cartesian_benchmark.json` |
| schema | `vwis-cartesian-benchmark-v1` |

每个 `records[]` 元素包含 `step`、`time`、`step_seconds`、
`post_projection_max_abs_divergence`、`net_flux`、三分量 `momentum` 和
`kinetic_energy`；顶层还包含网格、输入参数、终止时间、总耗时、BC、datum、
AMReX 运行/锁定版本、rank、compiler 和 CPU backend。周期 case 的 `net_flux` 是
由 cell divergence 积分得到的全局通量平衡量，而不是未经定义的边界速度积分。

## 🧪 实际验证

执行环境为 locked AMReX `26.04` CPU build（GCC `13.3.0`，Release，double，3D，
单 rank）。实际命令：

```bash
cmake --build build/amrex_port_p8 --parallel 2
ctest --test-dir build/amrex_port_p8 -R vwis_amrex_cartesian_benchmark --output-on-failure
```

结果：CTest `1/1` PASS；完整 JSON 报告中 `8` 个 step record，`final_time=0.008`，
每步 `step_seconds` 可解析且 `total_step_seconds` 已记录。8 步的
`post_projection_max_abs_divergence` 与 `net_flux` 均为 `0`（该制造路径的离散结果）；
动量保持在舍入误差量级，动能从约 `0.2480551134` 下降到约 `0.2348580287`。

## ⚠️ 未覆盖事项

- 没有 legacy vwis reference case、reference output 或压力物理标定
- 没有曲线 metric、IBM/FSI、AMR、MPI runtime 或 GPU runtime 验证
- JSON 是 benchmark 诊断报告，不是 plotfile/checkpoint；重启可比较性仍由 P8 专项测试负责
- 显式 Euler + projection 与 legacy SNES 不等价；P5-005 未实现

# AMReX P3 边界、数据流与诊断设计/测试记录（2026-08-24）

## 范围与结论边界

本增量只实现单层、均匀 Cartesian 的物理边界数据流：显式 BC 分类、cell/face
physical ghost、最小入口平面流量、出口压力 ghost/总流量约束及 MPI 全局诊断。
`advance_one_step()` 仍为 no-op。散度只用于通量恒等式诊断，不是 pressure RHS；
固定出口压力尚未被 Poisson/投影消费。未实现 P4/P5、曲线 metric、IBM/FSI、AMR
或完整 CFD。

## 数据流与责任边界

固定调用序列为：valid 写入并增加 `valid_epoch` → face `OverrideSync` →
`FillBoundary(periodicity)`（inter-box/MPI/periodic）→ physical cell ghost 与
boundary-normal `Ucont` → physical face ghost → 全局诊断。halo 和 physical
各记录 epoch；任何 stencil/诊断在 epoch 不一致时抛出 stale-ghost 错误。

`Ucont[d]` 始终是 $u_dA_d$。入口 profile 先在唯一边界面上做 MPI 全局积分，
再缩放到正的“进入域”目标流量；低侧入口写正坐标通量，高侧入口写负坐标通量。
出口压力只负责 `P/Phi` 的镜像 Dirichlet ghost；出口流量约束负责 normal
boundary face，两者不承担压力投影。无滑移/滑移/对称负责 velocity/flux，不暗中
设置 pressure datum。edge/corner physical ghost 采用 x→y→z 首个越界面的确定性
优先级；这是最小 stencil contract，不是高阶角点方案。

诊断按每个 pipeline stage 输出三类 freshness epoch、六个 physical plane 的
owner-unique flux 汇总、净外向通量、全域 `net face flux / cell volume` 的积分及
$L_\infty$。局部 sum/max 分别调用 `ReduceRealSum/ReduceRealMax`；face plane 使用
`OwnerMask/sum_unique` 的 local 模式后显式全局求和，避免跨 Box/rank 双计数。

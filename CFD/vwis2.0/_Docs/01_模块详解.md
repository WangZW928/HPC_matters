# 模块详解

> 证据边界：`Ucont` 与 `Ucat` 都是 3 分量 `Cmpnts` DMDA Vec；源码没有为 `Ucont` 创建严格 staggered 的 face DM。“面通量”是其离散使用语义。局部 stencil 一律通过 `DMGlobalToLocal*` 得到含 ghost 的 `l*` Vec。

## FlowSolver

`FlowSolver` 是单步流场求解的总控模块。它不直接实现离散算子，而是按顺序调用 `BcsUtility`、`LESModel`、`RHSSolver`、`WallModel`、`Integrator` 和 `PoissonSolver`。控制流程包括入口流量计算、LES 粘性更新、动量方程求解、压力投影、散度诊断和动能输出。

它求解的物理对象是不可压缩流动。速度以 `Ucont` 的逆变面通量形式保持守恒，以 `Ucat` 的笛卡尔形式参与物理模型。`CalculateDivergence` 用面通量差
`u_i - u_{i-1} + v_j - v_{j-1} + w_k - w_{k-1}` 乘中心 Jacobian 检查离散散度，并对 IBM 邻近点跳过诊断。

## PoissonSolver

`PoissonSolver` 实现投影法中的压力修正方程。它用 HYPRE IJMatrix/IJVector 构造 ParCSR 矩阵，默认使用 GMRES 加 BoomerAMG 预条件；若编译定义 `PCG_POISSON`，则改为 PCG。

关键步骤：

- `Setup` 为非固体压力自由度建立压缩编号 `Gid/Lid/Phi2`。
- `PoissonLHS` 组装 19 点模板，系数来自曲线网格面度量和 Jacobian。
- `PoissonRHS2_hypre` 先形成负的原始净面通量，再乘
  `-St/dt*timeCoeff`，故写入 HYPRE 的实际符号是
  `+St/dt*timeCoeff × raw_flux_imbalance`；它不乘中心 `Aj`。
- `RemoveNullspace` 在线性求解后从压力修正解减均值以固定 gauge；它不在
  solve 前修 RHS compatibility，也不注册 HYPRE nullspace。
- `Projection` 用压力修正梯度更新 `Ucont` 三个面向分量。
- `UpdatePressure` 执行 `P += Phi`。

该模块还包含 IBM 通量校正：`VolumeFlux` 统计 IBM 界面净通量，`AddIBMFluxtoOutlet` 可把 IBM 造成的体积通量补偿到出口。

## RHSSolver

`RHSSolver` 负责动量方程右端。它构造对流通量、粘性通量、压力梯度和可选平均压力梯度。对流通量在面上用 `Ucont` 乘插值后的 `Ucat`，内部默认有四阶中心型修正，`-second_order` 可退回二阶。靠近边界或 IBM 标记处自动退化到更局部的差分。

粘性项通过局部速度梯度和曲线坐标度量计算。若启用 LES，粘性中加入 `nu_t`；否则只使用分子粘性 `nu=1/Re`。最终 RHS 被投影回逆变速度分量，并在固体界面和物理边界处置零。

## Integrator

`Integrator` 使用 PETSc SNES 解非线性动量方程。默认 `SNESNEWTONTR`，Jacobian 默认 `MatCreateSNESMF` 矩阵自由有限差分；若编译启用 ADIC，则可用显式着色 Jacobian。线性求解器在后续步设为 GMRES，默认预条件为 `PCNONE`。

`SolveFunction` 是 SNES 回调。当前 `getTimeCoeff()==1` 的实际残差可概括为：

`-(U-U_old)/dt + 0.5*F(U) + 0.5*F_old - Dp = 0`

源码还保留使用 `Ucont_rm1` 的 BDF2 分支，但因时间系数硬编码为 1.0
而不可达。求解后它更新 `Ucont`、同步 ghost 层、做部分边界修正并调用
`Contra2Cart` 更新 `Ucat`。

## LESModel

`LESModel` 支持 `-use_les` 开关。`-les 1` 是常数 Smagorinsky，直接把 `Cs` 设为 `0.01`。动态模型计算应变率 `Sij`、测试滤波后的 Leonard/Germano 张量量 `LM/MM`，并令 `Cs = 0.5 LM/(MM+eps)`。可通过 `-i_homo_filter/-j_homo_filter/-k_homo_filter` 做均匀方向平均，也可用 `-testfilter_ik` 使用二维均匀 Simpson 过滤。

`ComputeEddyViscosity` 用

`nu_t = Cs * Delta^2 * |S|`

其中默认 `Delta=(1/J)^(1/3)`，`-filter_size` 相关逻辑部分被硬编码重置，实际多数路径使用体积滤波尺度。近 IBM/壁函数区域会把 `nu_t` 限制为零或下限。

## WallFunctions / WallModel

`WallFunctions` 提供局部壁函数工具：

- `noslip`：线性无滑移插值，估计 `u_tau=sqrt(U_t/(sc Re))`。
- `freeslip`：保留切向速度，对法向速度作距离比例缩放。
- `wall_function_s`：使用 1/7 幂律或粗糙壁对数律估计壁面速度。
- Cabot 型积分函数：用近壁涡粘形式 `kappa y+ [1-exp(-y+/19)]^2` 对速度剖面积分，并用 Newton 法求 `u_tau`。

`WallModel` 是网格边界和 IBM 边界的壁面模型。它计算壁面模型粘性通量 `d_lVisc*_wm`，然后在 `Solve` 中用壁模通量替代或修正原 RHS 粘性贡献。支持指定 `imin/imax/jmin/...` 的壁模区域和 `-IB_wm` 的 IBM 壁模。

## ImmersedBoundary

`ImmersedBoundary` 读三角面 UCD 格式 IBM 几何，维护 `IBMNodes` 和每个体的 `IBMList`。搜索流程包括：

- 为体表三角面建立 40x40x40 空间桶。
- 通过射线-三角相交判断单元中心在固体内外。
- `Nvert=4` 表示固体内部，`Nvert=2` 表示近界面；已有体可能用 3/1 区分历史/多体。
- 对 `Nvert=2` 的点查找最近三角面和 image/interception point。
- 把插值点索引和三角面重心系数存入 `IBMInfo`。

`IBMInterpolationAdvanced` 根据 `IBMInfo` 从流体插值点、表面速度和壁函数构造近界面速度，并计算表面压力、剪切、Reynolds 应力等输出量。该方法是 sharp-interface 插值边界处理，而不是连续体力源项型 IBM。

## CurvGrid

`CurvGrid` 负责结构化曲线网格。输入可为：

- `grid.dat`：块数、尺寸、x/y/z 全场数据。
- `xyz.dat`：三个方向坐标向量生成张量积网格。
- 二进制 `grid.dat`。
- `-uniform` 直接由 `IM/JM/KM` 和 `Lx/Ly/Lz` 生成均匀网格。

它用 PETSc `DMDACreate3d` 建立标量 DMDA 和坐标向量 DMDA。`FormMetrics` 由节点坐标构造单元中心、中心度量、i/j/k 面度量与面 Jacobian。`Csi/Eta/Zet` 及各方向面 metric 是局部边向量叉积得到的面积余因子，不是裸 $\nabla\xi^i$；`Aj/IAj/JAj/KAj` 存相应映射行列式的倒数。该定义也是 `Ucont` 具有面体积通量语义的直接依据。

## StructSolver + FSI

`StructSolver` 管理结构子迭代。每个内迭代先保存旧 FSI 状态，再由 `FSI::CalculateForces` 积分流体压力和粘性力，随后更新平移或旋转并触发 IBM 搜索。`-str` 控制强耦合迭代次数，`-str_tol` 控制结构收敛阈值。

`FSI` 的平移模型保存 6 个自由度数组，位置和速度交错存储，如 x 与 dx/dt、y 与 dy/dt、z 与 dz/dt。结构方程是简化弹簧-阻尼-质量形式，使用流体力 `F_x/F_y/F_z`、约化速度、阻尼和质量参数迭代更新。旋转模块支持指定角速度、流体力矩驱动和绕轴旋转，并更新 IBM 顶点位置和表面速度。

## BcsUtility

`BcsUtility` 处理边界条件、初场和通量。边界类型宏包括 `SOLIDWALL=1`、`SYMMETRIC=3`、`OUTLET=4`、`INLET=5`、`FARFIELD=6`，代码中还使用 `-1/-2/10/11/12` 等算例特定类型。它支持入口流量、出口缩放、伪周期流入、回收入口剖面、高斯扰动、驱动腔、Couette、管流等多种研究算例路径。

`IbBC` 把 IBM 邻近面通量和速度置为合适边界值。`CalculateInletArea/CalculateInflowFlux/ScaleInitialFlow` 用面积和通量统计控制流量守恒。

## UData

`UData` 是字段存储中心。它创建和销毁：

- 全局/局部 `Ucont/Ucat/P/Nvert`。
- 历史量 `Ucont_o/Ucont_rm1/Ucat_o`。
- RHS、压力梯度、壁面摩擦速度 `Ustar`。
- IBM 旧掩码和压力副本。
- 平均与相位平均统计字段。

I/O 通过 PETSc Viewer 完成，支持 binary 和 HDF5。输出命名包括 `vfield`、`ufield`、`pfield`、`nvfield`，重启按相同命名读取。

## PlaneExtraction / PointProbe

`PlaneExtraction` 从 `savekplanes` 读要保存的 k 平面，抽取 `Ucat` 并写入二进制 inflow 文件，可用于入口湍流回收。`Read` 按 `-recycle`、`-read_inflow_period` 和 `-scale_velocity` 读取流入面。

`PointProbe` 从 `savepoints` 读物理坐标，初始化时找最近单元中心，运行时输出速度、压力、面通量估计、涡量、速度梯度和压力梯度。

## Timer

`Timer` 是 PETSc `PetscTime` 的轻量封装，记录单次、累计、平均时间和调用次数。当前主流程更多直接调用 `PetscTime`，该类并未被广泛集成。

## functions / ibm_functions

`functions.c/h` 提供 `Cmpnts`、`Index`、向量代数、MPI 全局归约、曲线坐标变换、标量/速度梯度差分。差分函数会根据 `Nvert` 在 IBM 附近自动改用单边差分。

`ibm_functions.c/h` 定义 IBM/FSI 数据结构和几何工具：Moller-Trumbore 射线三角相交、点到线距离、三角形内点判断、重心插值、链表管理等。

## data.py

`data.py` 是 Python 2 后处理脚本，用 numpy/h5py 生成 `grid.h5`、瞬时 XDMF、时间序列 XDMF，以及平均量 HDF5/XDMF。它假定求解器以 HDF5 输出 PETSc Vec，数据集名称如 `/ucat`、`/ucont`、`/pressure`、`/nvert`。

## 审阅校正：模块契约与未验证项

- `PoissonSolver::SolvePoisson` 只在 `ti==tistart` 组装矩阵/创建 HYPRE 求解器；移动 FSI 后的重组装分支是注释代码，不能写成已实现。
- `CalculateMinimumDt` 仅诊断 `|Ucont^q Aj|^{-1}` 等尺度，`main.C` 不使用其返回值更新 `dt`。
- `Timer`、`PlaneExtraction`、`PointProbe` 与 `data.py` 已纳入审阅；`data.py` 是后处理，既不参与求解器数据依赖，也不参与 MPI 通信。

# vwis2.0 整体架构

> 审阅状态（2026-08-20）：本文的“实现”仅指当前 `vwis2.0/` 可见源码；未随仓库提供的手册、输入和性能日志不能作为实现证据。树内未发现 level-set、相分数、密度/黏度场、AMR 或 GPU kernel，故历史 VFS 的这类能力不能标为本版本已实现。

## 求解器定位

vwis2.0 是一个基于 PETSc/MPI 的三维不可压缩流动 LES 求解器，支持结构化曲线网格、浸入边界方法（IBM）以及可选的流固耦合（FSI）。主程序注释中称其为 “VWiS 2.0 with interface for ROM”，但当前代码主体是直接数值/LES 流场推进器，不是 ROM 求解器本身。

求解变量主要有两套速度：

- `Ucont`：守恒形式/逆变速度，存储在曲线网格单元面上，用于通量散度、连续性约束和压力投影。
- `Ucat`：笛卡尔速度，主要用于对流/粘性项、LES 应变率、壁面模型、输出和探针。

压力 `P` 存储在标量 DMDA 上。IBM 标记量 `Nvert` 用浮点标记固体、近边界与流体单元。曲线网格几何由 `CurvGrid` 生成的中心和面度量 `Csi/Eta/Zet`、`ICsi/JCsi/KCsi` 等提供。

## 数值路线

代码实现的是不可压缩 Navier-Stokes 方程的投影类算法：

1. 在曲线坐标中构造对流、粘性和 LES 亚格子项。
2. 使用 PETSc SNES 对动量方程作隐式/非线性求解，未知量是 `Ucont`。
3. 用压力 Poisson 方程求压力修正 `Phi`。
4. 用 `Phi` 修正面通量，使离散散度接近零。
5. 更新压力 `P += Phi` 并把逆变速度转换为笛卡尔速度。

LES 模型包含常数 Smagorinsky 和动态 Smagorinsky 逻辑。动态模型计算 Germano 形式的 `LM/MM`，可选均匀方向平均和 Simpson/二维均匀测试滤波，最后限制 `Cs` 在 `[0, max_cs]`。

IBM 是偏 sharp-interface 的插值/镜像点方法。它不使用连续 delta 函数直接扩散体力，而是：

- 对三角面浸入体做空间分桶和射线/三角相交搜索。
- 用 `Nvert` 标记固体内部和近界面单元。
- 为近界面单元建立 `IBMInfo` 插值信息。
- 在 `IBMInterpolationAdvanced` 和边界处理里把边界速度设为体表速度、镜像点速度或壁函数模型给出的速度。

FSI 通过 IBM 几何运动实现。结构自由度由 `FSInfo` 保存，平移和旋转均会更新 IBM 顶点位置与体表速度；若几何变化影响固体掩码，则重新做 IBM 搜索。

## 代码结构

入口文件是 `main.C`。它按以下顺序创建对象：

- `CurvGrid`：读网格、边界类型、构造 PETSc DMDA 和曲线度量。
- `UData`：分配流场、压力、历史量、统计量和文件读写。
- `ImmersedBoundary`：读 IBM 三角面网格，搜索固体/界面单元和插值信息。
- `FSI` 与 `StructSolver`：结构状态、力矩计算、平移/旋转更新和强耦合迭代。
- `BcsUtility`：入口/出口/壁面/IBM 边界条件、初场和通量缩放。
- `LESModel`、`WallFunctions`、`WallModel`：LES 亚格子粘性和近壁处理。
- `RHSSolver`：动量方程右端，对流、粘性、压力梯度与源项。
- `Integrator`：PETSc SNES 非线性动量积分器。
- `PoissonSolver`：HYPRE 压力 Poisson 和投影修正。
- `FlowSolver`：组织一次流场步进。
- `PointProbe`、`PlaneExtraction`：点探针和流入面抽取/回收。

## 主数据流

`main.C` 中先读 `control.dat` 到 PETSc options，再初始化网格、数据、IBM/FSI、探针和重启数据。初始 IBM 搜索后，如果非重启，则由 `BcsUtility` 生成初场并缩放初始流量。时间循环中，若 `-str` 大于 1，则结构和流场在内循环中作强耦合迭代；`-str 1` 退化为弱耦合。

一次流场推进由 `FlowSolver::Solve` 驱动：

1. 估算最小时间步尺度。
2. 读回收流入面并计算入口流量。
3. 初始化 RHS、壁面模型和 LES 数据。
4. 计算 LES 系数和亚格子粘性。
5. 组装旧步 RHS 和压力梯度。
6. 计算壁面模型修正。
7. `Integrator` 解动量方程。
8. `PoissonSolver` 解压力修正并投影速度。
9. 重新施加 IBM/边界条件，更新 `Ucat`。
10. 输出散度和动能诊断。

## 实现质量观察

代码体现了成熟 CFD 研究代码的特点：数值功能覆盖较多，PETSc DMDA 和 HYPRE 并行求解器使用充分，但模块内部耦合较强，许多物理选项通过全局 PETSc options 字符串控制，缺少集中配置结构。静态可确认的维护风险包括：`PoissonRHS2_hypre` 将局部 `JAj` 取得 `getlKAj()`，`WallFunctions::utau_wf` 光滑壁分支无返回值，以及 `StructSolver::CheckConvergence` 将“大于容差”的结果写入 `converge`，旋转支路还会把容差赋为布尔值。这些是审阅发现，不代表已在某算例触发；本次未改源码。
